# Security Policy

## Supported version

Security reports are welcome for the current default branch.

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, access tokens, OAuth secrets, personal data or private media in a public issue.

Use GitHub's **Private vulnerability reporting** feature on this repository if it is enabled. If it is not enabled, contact the repository owner privately through the contact method listed on the GitHub profile and include:

- A concise description and impact.
- Steps to reproduce or a proof of concept.
- Affected files, versions and configuration.
- Any suggested mitigation.

Please allow reasonable time for investigation and a fix before public disclosure.

## Sensitive data

Never commit `.oauth.key`, OAuth tokens, local settings, credentials, private videos or workspace data. Revoke exposed credentials immediately.
