- CrewAI ? https://github.com/crewAIInc/crewAI ? MIT License. Role-based agent and Flow orchestration reference.
- LangGraph ? https://github.com/langchain-ai/langgraph ? MIT License. Stateful, resumable workflow and human-in-the-loop reference.

The application's own source code remains distributed under the repository's MIT License. Re-check each upstream repository's license and dependencies before copying or vendoring any code in a future release.
